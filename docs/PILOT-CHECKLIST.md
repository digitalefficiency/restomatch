# Pilot Checklist — RestoMatch

תיק להשלמה עם מסעדת פיילוט. עברו על הסעיפים, סמנו ✓, ושלחו ל-pilot-coordinator לפני יום ההפעלה.

## 1. נתונים בסיסיים על המסעדה

- [ ] שם המסעדה (כפי שיופיע על המסכים)
- [ ] ח״פ / עוסק מורשה
- [ ] שעות פעילות (לקביעת cron של "ציפיות יום")
- [ ] שיעור מע״מ (ברירת מחדל 17%)
- [ ] מטבע ברירת מחדל (ILS)

## 2. תפקידים — אנשי קשר במסעדה

לכל תפקיד: שם מלא, מייל, וטלפון (לקבלת WhatsApp/Push).

- [ ] **בעלים** — מאשר חריגות חמורות, מקבל KPIs ב-WhatsApp
- [ ] **מנהל משמרת** — עובר על תור אישורים, מאשר בינוניות
- [ ] **מקבל סחורה (יוסי/אבי/…)** — עובד עם האפליקציה הניידת
- [ ] **חשב/הנהלת חשבונות** — אחראי על Exports
- [ ] **שף** (אופציונלי) — מקבל התראות על פריטים פגומים

## 3. ספקים

טבלת CSV (אקסל) עם כל הספקים שעובדים איתם המסעדה:
- [ ] שם הספק (בעברית)
- [ ] ח״פ (אם ידוע)
- [ ] איש קשר + טלפון
- [ ] תדירות אספקה רגילה (כל יום, יומיים, פעם בשבוע)
- [ ] שעות אספקה רגילות (06:00, 08:00, וכו')

## 4. קטלוג מוצרים

- [ ] רשימת המוצרים שמזמינים באופן קבוע (יצוא מ-Market Man / זסטר / קובץ אקסל ידני)
- [ ] לכל מוצר: שם, יחידת מידה, קטגוריה, ספק/ים, מחיר מצופה

ניתן לדלג ולתת לסנכרון מ-Market Man למלא אוטומטית.

## 5. אינטגרציות

### Market Man (אופציה ראשית להזמנות)
- [ ] חשבון Market Man פעיל
- [ ] API key מ-Market Man (יש לבקש מהם דרך support@marketman.com)
- [ ] רשימת ספקים שמסונכרנת ל-Market Man

### Email Inbox (גיבוי / ספקים שלא ב-Market Man)
- [ ] גישת OAuth ל-Gmail/Outlook של תיבת ההזמנות
- [ ] איזה label / folder לסרוק

### WhatsApp Business (להתראות)
- [ ] Meta Business verified (אם לא — נתחיל עם push notifications + SMS)
- [ ] מספר WhatsApp Business
- [ ] Phone Number ID + Access Token

## 6. OCR — חשבוניות

- [ ] **חשבון Google Cloud** עם Document AI מופעל
- [ ] Project ID + Location (eu או us)
- [ ] Processor ID של Invoice Parser
- [ ] Service Account JSON עם הרשאות `roles/documentai.apiUser`

- [ ] **Anthropic API key** (לקריאת פריטי שורה בעברית)
- [ ] Model: `claude-sonnet-4-6` (מומלץ — תמיכה חזקה בעברית)
- [ ] Budget cap חודשי (מומלץ: $50 בחודש לפיילוט)

## 7. תשתית

- [ ] **Neon Postgres** project פתוח (production tier מספיק לפיילוט)
- [ ] Connection string
- [ ] pgvector + pg_trgm extensions מופעלות
- [ ] **Upstash Redis** (לתורי BullMQ)
- [ ] **Cloudflare R2** או S3 לאחסון תמונות
- [ ] **Vercel project** ל-web (apps/web)
- [ ] **Fly.io / Render** ל-worker
- [ ] **Expo EAS** ל-mobile builds

## 8. תאימות חוקית

- [ ] DPA (Data Processing Agreement) חתום עם ספקי הענן
- [ ] התקנת תקנות הגנת הפרטיות — review בוצע
- [ ] שיעור מע״מ במערכת תואם לחוק העדכני (17% נכון ל-2026)
- [ ] חשבוניות ישראל (מספרי הקצאה) — נדחה לשלב ב' אלא אם חוק דורש מיידית

## 9. הכשרה לצוות (יום ההפעלה)

- [ ] הסבר של 15 דקות לבעלים — סקירת KPIs + תור אישורים
- [ ] הסבר של 20 דקות למקבל הסחורה — אפליקציה ניידת, סריקת חשבונית, מעבר על שורות
- [ ] הסבר של 10 דקות לחשב — איפה ה-Exports, פורמט קובץ 1000
- [ ] צ'אט WhatsApp פתוח עם הצוות שלנו לבעיות בזמן אמת

## 10. מדדי הצלחה לסיום הפיילוט (חודש 1)

- [ ] 100% משלוחים נסרקים בתוך שבועיים
- [ ] זמן ממוצע לקבלת משלוח: <3 דקות
- [ ] % discrepancies שזוהו: >70% מסך המשלוחים
- [ ] "leak" כספי שזוהה: לפחות 1.5% מסך הרכש
- [ ] שביעות רצון של הצוות: >4/5 ב-survey

## 11. הסכמים

- [ ] חוזה פיילוט בתשלום (שבועיים onboarding חינם + 8 שבועות מוזל)
- [ ] NDA (אם רלוונטי)
- [ ] הסכמה לפרסום case study בסיום מוצלח
