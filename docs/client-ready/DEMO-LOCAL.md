<div dir="rtl">

> **למה:** אם הענן (Vercel / Supabase) לא עונה בבוקר הדמו, מציגים את אותו מוצר ואת אותם מספרים מהמחשב. בלי אינטרנט, בלי מיילים, בלי וואטסאפ ובלי תשלומים.

## הפקודה האחת

בטרמינל, מתוך תיקיית הפרויקט (`~/restomatch`):

```bash
git pull && scripts/demo-local.sh
```

**כמה זמן זה לוקח:**
- בפעם הראשונה 8–12 דקות. זה כולל הורדת Postgres (Docker או Homebrew) ובנייה של האפליקציה, שלוקחת 3–6 דקות.
- בכל הרצה אחרי זה כ-30 שניות, כי הבנייה נשמרת. כל הרצה מוחקת וזורעת מחדש את נתוני הדמו.

**מה צריך במק:** Node 22 ו-pnpm. בנוסף **אחד** מאלה:
- Docker Desktop פתוח;
- Homebrew. אם אין Postgres, הסקריפט מתקין לבד `postgresql@16 pgvector`.

אם חסר משהו, הסקריפט עוצר ואומר בדיוק מה להתקין.

**בסוף מודפס:**
- הכתובת: **http://localhost:3000**. עדיף ב-Chrome.
- הסיסמה לכל המשתמשים: **`RestoMatch-Demo-2026!`**

## עצירה

```bash
scripts/demo-local.sh stop
```

הפקודה עוצרת את האפליקציה ואת ה-worker. Postgres נשאר לרוץ, ואין בזה נזק. `scripts/demo-local.sh status` מראה מה רץ. הלוגים נמצאים ב-`.demo-local/`.

## ✅ הערב: הרצת ניסיון אחת

1. `git pull && scripts/demo-local.sh` ומחכים להודעה הירוקה.
2. נכנסים כבעלים ובודקים את 5 הכתובות שלמעלה.
3. נכנסים כמקבל סחורה בחלון Incognito ועוברים פעם אחת על קבלה מלאה עד "Close receipt and save".
4. `scripts/demo-local.sh stop`.
5. **בבוקר הדמו** מריצים שוב `scripts/demo-local.sh`, כ-30 שניות. זה זורע מחדש, כך שהקבלה מאתמול נמחקת וההזמנה של HaSharon חוזרת להיות פתוחה.

**אם נתקע:** הסקריפט כותב בשורה אדומה מה חסר ואיפה הלוג. נפוץ:
- "port 3000 is already in use": סוגרים את מה שרץ, או מריצים `DEMO_PORT=3001 scripts/demo-local.sh`.
- "No Postgres found": פותחים את Docker Desktop ומריצים שוב.
