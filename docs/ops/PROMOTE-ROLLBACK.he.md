# העלאה לאוויר (Promote) וחזרה לגרסה קודמת (Rollback)

<div dir="rtl">

**למי:** רום. אתה היחיד שמבצע Promote או Rollback.

**איך זה עובד אצלנו:** הפרויקט `project-6bs41` ב-Vercel מוגדר כך שבנייה חדשה **לא** עולה לבד לכתובת `https://restomatchrrr.vercel.app`. כל בנייה, גם מ-`main`, מחכה ל-**Promote** ידני. כך אתה מחליט מתי גרסה עולה.

---

## 1. Promote לבנייה מוכנה

1. **לפני כל Promote:** גיבוי `pg_dump` לפי `BACKUP-RESTORE.he.md` סעיף 2. בלי `✔ BACKUP OK` לא ממשיכים.
2. Vercel → **Deployments** → מוצאים את הבנייה (לפי הקומיט או הענף `main`) → הסטטוס חייב להיות **Ready**.
3. **⋯** → **Promote** → מאשרים.
4. בודקים: `https://restomatchrrr.vercel.app/api/healthz`.

**מה צריך לראות:**
- הבנייה מסומנת **Current**.
- ב-`/api/healthz` תשובה 200, והשדה **`commit`** הוא הקומיט של הבנייה שקידמת (40 תווים; משווים את 7 הראשונים לזה שמופיע ב-Vercel).
- כניסה לאתר עובדת.

**אם לא:** `commit` אחר → ה-Promote לא נקלט; מרעננים אחרי דקה. 500 או שגיאה → Rollback מיידי (סעיף 3).

רושמים ב-`docs/ops/OPS-LOG.md`: שעה, קומיט, תוצאה.

## 2. שינוי משתנה סביבה = Redeploy + Promote

שינוי ב-Environment Variables **לא** משפיע על הבנייה שרצה. אחרי כל שינוי:
1. Deployments → הבנייה ה-**Current** → **⋯** → **Redeploy**.
2. מחכים ל-**Ready**.
3. **Promote** לבנייה החדשה (סעיף 1, כולל בדיקת `/api/healthz`).

## 3. Rollback

**Rollback = Promote לבנייה קודמת שהייתה תקינה.** Vercel → Deployments → הבנייה הקודמת (Ready) → **⋯** → **Promote** (או **Instant Rollback**, אם מוצע).

**הכללים:**
- **אף פעם לא לבנייה שנוצרה לפני א׳ 1.11.** בנייה ישנה רצה עם הסיסמאות שהוחלפו ב-1.11: היא לא תתחבר למסד, ותחזיר לשימוש סודות שנחשפו.
- **מה-5.11 (ציקטי פעילים): אף פעם לא מתחת ל-RC1.** אם בכל זאת נאלצים לחזור לבנייה שלפני RC1: **קודם** Anthropic Console → API Keys → מנטרלים (Disable) את המפתח של הפרודקשן, ורק אז Rollback. כך גרסה ישנה לא תשלח חשבוניות של לקוח אמיתי לעיבוד בדרך שלא נבדקה.
- אחרי Rollback: בודקים `/api/healthz` (סעיף 1), ומודיעים למפתחים מה נשבר.

## 4. מתי מותר

| מה | מתי |
|---|---|
| Promote רגיל | **ב׳–ה׳, 15:00–17:00** בתקופת ההקפאה |
| Rollback | בכל שעה, **חוץ משבת** |
| תיקון דחוף (S1) שאישרת | בכל שעה, **חוץ משבת** |
| **אסור** | מ-**יום ו׳ 12:00** ועד **אחרי צאת שבת**: אין Deploy ואין Promote (חוץ מ-Rollback במקרה חירום אמיתי) |

## 5. איך לקרוא את `/api/healthz`

פותחים `https://restomatchrrr.vercel.app/api/healthz`. התשובה היא JSON:
- `"status": "ok"` וסטטוס 200: שרת האתר עלה. **זה לא בודק את מסד הנתונים**, ולכן אחרי כל Promote בודקים גם כניסה לאתר.
- **`commit`**: הקומיט שרץ עכשיו בפרודקשן. משווים ל-Vercel → Deployments (7 התווים הראשונים) או ל-GitHub.
- `time`: שעת השרת (UTC). לא נדרש לבדיקה.
