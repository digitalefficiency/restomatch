# AU-01 · Automations switch-on: pilot defaults and the owner's "אוטומציות" page
**One line:** the automation that already exists gets switched on, and the owner can see and control it. Today the owner cannot turn anything on: the only switch is the platform-admin console (`admin.setFeatures`, `routers/admin.ts:370-403`). `priceAlerts` and `vatAtRisk` are off for every pilot tenant, so a VAT-at-risk sum like the lab's ₪1,123.20 never reaches ציקטי.
