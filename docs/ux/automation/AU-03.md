# AU-03 · Recovery chase loop v1: one overdue rule, a pre-addressed supplier reminder draft, a credit that asks to be confirmed

**One line:** found ₪ becomes returned ₪ more often. The 08:30 run gives owner + manager (+ bookkeeper, opt-in, default on) one digest of suppliers with no reply for 7+ days; each has a pre-addressed **draft** reminder (wa.me / mailto, one click, never sent by us). A credit line on a later invoice becomes a T2 suggestion "אשרו זיכוי ₪X" with an oldest-first proposal that a human confirms.

2. `claimed` without a letter is "טרם נשלח מכתב", never "no reply" / late.
3. Membership per claim; display per supplier; ₪ summed per claim (job = web).
4. Digest recipients owner + manager (+ bookkeeper when on); receiver/chef never; dedupe `au:A12:<rid>:<userId>:<ilDate>`; no outbox row targets a supplier.
5. Partner wording only (בקשת זיכוי · תזכורת קטנה · חשבונית זיכוי; never דרישה / תביעה / חוב / באיחור / מחלוקת).
6. Credit suggestion = `allocateCredit` oldest first; no write before confirm; confirm → `recordCreditNote`; foreign line/claim → NOT_FOUND; other supplier's claim → BAD_REQUEST `supplier_mismatch`; flag off → FEATURE_DISABLED; receiver/chef → FORBIDDEN.
