# AU-04 · Role briefs on the existing schedules: everyone hears what is theirs, once, at the right time
**One line:** the jobs that already run every day finally tell the right person the right thing:
- **06:00:** the receiver gets the day's trucks, with no ₪;
- **09:00:** the chef and manager hear that an unsent draft is not an order;
- **10:00:** the manager gets a ready-to-send, pre-addressed "where is the truck?" message, and the receiver hears the truck is late;
- **19:00:** each finance role gets its decisions waiting, oldest first, with no never-claimable ₪;
- **match alerts:** they fire again when a re-match finds something new.

Today:
- `daily-expectations` computes the truck list and writes only an `audit_log` row nobody reads (`dailyExpectations.ts:123-132`);
- an unsent draft silences the order reminder (`orderReminders.ts:81-90`), and the chef is not a recipient;
- late trucks e-mail the restaurant with no supplier action (`supplierDelays.ts:121-155`);
- a re-match never notifies (`matchInvoice.ts:190`);
- ₪ is formatted inline (`notifyHelpers.ts:64-68`).

Hours (catalogue A3–A7, ASSUMPTIONS): ≈0.6–2.4 h/week across roles (receiver prep, manager chasing, owner hunting for what waits) ≈ **₪255–1,030/month hours-₪** (sum of the five rows, overlaps not netted). ₪ effect: none of its own. It protects the ₪ the other packages find (decisions before payment keep the cheaper offset channel). This is said so, not claimed.

**Owner agent:** ocr-procurement-engineer (owns `apps/worker`; web-feature-engineer writes the brief templates; rtl-design-steward + money-format-marshal sign every ₪ string; tenant-security-warden reviews role payloads). **Device:** server (e-mail/in-app payloads; no new screen). **Effort:** M–L. Ship as 3 PRs:
- a = `briefs/**` builders + receiver brief + `notifyHelpers`;
- b = evening digest + order reminders + late trucks;
- c = match alerts on re-match.

**humanPR:** no (`cron.ts` and `outbox.ts` untouched: every brief rides an existing slot; no schema change).
