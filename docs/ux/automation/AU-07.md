# AU-07 · Automation telemetry: measured minutes, zero-touch share and the ₪ funnel per restaurant
**One line:** the platform admin (and later the owner) sees, per restaurant per Israel week, how many documents came in, what share went through untouched, how long arrival → matched took, how old decisions get, which alerts led to an action, and where the ₪ stops on the way found → decided → claimed → sent → credited → recovered.
