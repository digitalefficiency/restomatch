## 5. Acceptance criteria
1. **Shortlist.** `quickstartShortlist` (chef, flag `recipes`) returns products with ≥1 `price_history` row in the last 90 Israel days, ranked on the server by ₪ bought (Σ invoice line totals, integer agorot), each with last paid unit price, unit, supplier and date. Top 150; category filter. **Role split (owner rule: chef ₪ only on orders and recipes):** for the **chef** the payload carries the rank order, last paid unit price and unit only (recipe inputs), **no spend total**; owner/manager also get "₪ נקנה" per product. Copy: "התחילו מהמוצרים שקניתם · 112 מוצרים מ-90 הימים האחרונים".
2. **Empty state.** On an empty recipes page the card "בונים מתכון ראשון? בחרו מנה, והמרכיבים כבר כאן" replaces the blank list; never shown on any home or onboarding screen (test: the component is imported only under `dash/recipes/**`).
3. **Unmapped lines.** Invoice lines of the last 90 days with no product and ≥₪300 bought are listed and sent to W3-10's "לקשר" queue on tap (owner/manager links them; the chef cannot link). Owner/manager see "לא מקושר · ₪1,240"; the **chef** sees the same list **without ₪** ("לא מקושר · נקנה לאחרונה 12.10"); the ≥₪300 filter runs on the server.
4. **Outlines (PR b).** The chef pastes menu text or uploads a photo; the W3-04 tool returns outlines `{dish, ingredients: [{productId, qty: null | {value, estimated: true}}]}`. `skeletons.ts` drops every ingredient not in the shortlist, every price field, and any quantity not flagged estimated. Each outline opens as an **unsaved** recipe in W3-02's editor, labelled "טיוטה של RestoMatch"; "הערכה" quantities are highlighted until edited.
5. **Chef confirms each recipe.** Nothing is saved without the chef's `save` on that recipe; a bulk "שמור הכל" does not exist (test).
6. **₪ only from price history.** Plate cost in a draft uses `latestPrices`; a model response containing ₪ or a price is ignored (test with a hostile fixture). Menu price is typed by the owner/chef, never inferred.
7. **Roles.** Chef, manager, owner may use the shortlist and outlines; bookkeeper read-only per W3-02; **receiver FORBIDDEN**. No chef notification carries ₪.
8. **Acceptance tracking.** Each outline records accepted / edited / discarded (W3-04 tracking). Below 60% acceptance over 20 outlines the tool turns off for the tenant (W3-04 kill-switch).
9. **KPI hook.** Audit `recipes.quickstart_shortlist_opened`, `recipes.quickstart_outline_accepted` (`after: { edited: boolean }`), `recipes.quickstart_mapping_sent`. AU-07 reports: recipes created in the first 14 days after `recipes` is on, minutes per recipe (telemetry), outline acceptance %.
