## 4 Slices
- **a (now):** guards + API invariants, warn mode, per-area counts.
  - Guards (`scripts/guards/**`, run `pnpm --filter @restomatch/web guards`; `--json`, `--strict` for W4-01):
    1. `onchange-mutation` — `onChange` on select / radio / checkbox reaching a mutation, server action, `run()` / `startTransition` or `fetch` (allow-list for settings toggles).
    2. `money-swallow` — `.catch(() => null | [] | undefined)` on money procedures; `?? 0` on `*Ils` / `*Agorot` in server components.
    3. `receiver-idb-delete` — IndexedDB deletes in receiver code outside `outbox.ts`.
    4. `status-literals` — status literal arrays outside the lifecycle modules.
    5. `client-api-value-import` — value (non-`type`) imports of `@restomatch/api` in `'use client'` files.
  - API invariants (`api/__tests__/invariants/**`):
    1. `get-writes-nothing` — statement log over every GET (`query`) in a set that includes `recovery.list` and `monthlyReport.{preview,digest}`; any INSERT/UPDATE/DELETE/`FOR UPDATE` is a violation.
    2. `one-letter-per-discrepancy` — no discrepancy sits on more than one credit-request letter: DB side (≤1 live claim per discrepancy, claim supplier = invoice supplier) in `api/__tests__/invariants/db.test.ts`; letter-model side (500 seeded scenarios over `buildLetters`) in `web/lib/__tests__/g16-letters.test.ts`.
    3. `late-defined-once` — "late" is computed only in `api/lib/deliveryState.ts`; other modules call it.
    4. `one-metric-definition` — each ₪ metric has one source (interim signature scan → G-14 registry ids).
  - Every detector has a self-test that plants a violation and asserts it is caught (hard), so warn mode is never vacuous.
