## 4. Slices
- **a · matrix (now, this PR).**
  1. Pure scope: `parseBranchScope('all'|'<uuid>'|'g:<billingAccountId>')` in `apps/web/lib/nav/scope.ts` (URL side) and the server mirror `resolveMatrixScope(rows, activeRestaurantId, scope)` in `routers/chain.ts`. Group = billing account. An id not found in the caller's RLS-derived memberships → NOT_FOUND (no existence oracle).
  2. Read-only chain scope for bookkeepers: the matrix accepts an owner **or** bookkeeper membership on the active branch, and lists only branches on the same billing account where the caller holds that same kind of role. Writes (`renameBranch`, `addBranch`) stay owner-only.
  3. `approvals.queueSummary`'s body → exported `computeQueueSummary(db, rid, role, filters)` (pure refactor, same rows, same ₪), so the matrix's "₪ awaiting" equals the approvals tile per branch.
  4. `chain.matrix`: per branch in its own `inBranch` (RLS): `computeBranchSnapshot` (unchanged), `computeQueueSummary` (₪ awaiting decision), `computeRecoverySummary` (open credit requests ₪ = outstanding, recovered ₪), completeness = checked ÷ (checked + waiting to link). A branch that throws becomes an error row (`status: 'error'`), never a failed page. The pinned total row = `aggregateChain` over the OK rows (so it equals the chain KPIs by construction) + Σ awaiting / open / recovered in integer agorot; `partial: true` when any branch errored. Cell state per branch: `no_data` (T4) · `pending` (only invoices waiting to link) · `clean` (T3, checked spend and 0 leak) · `leak`.
  5. `chain.branchPeek` (the 520 px peek): one branch's top suppliers and the biggest open item, after the same membership check.
  6. `dash/chain/matrix/page.tsx`: server-rendered matrix (RTL, `formatIls()` only, names wrap, heatmap oldest → newest with newest next to the names), every cell a drill link, per-branch error cards, the three states with no emoji; a local nav entry in `nav/routes/chain.ts`.

## 5. Acceptance
- `b=all|<id>|g:<group>` parses strictly (anything else → `all`), and the server rejects an id/group outside the caller's memberships with NOT_FOUND.
- Matrix total row: `leakIls`, `spendIls`, `claimedIls`, `caughtBeforePaymentIls` equal `chain.overview.totals` for the same view, to the agora; awaiting / open / recovered totals equal Σ of the branch rows in agorot.
- A branch whose computation throws shows an error card; the other branches and the total (marked partial) still render.
- Bookkeeper on a chain account: `chain.matrix` and `chain.branchPeek` work read-only; every chain write still FORBIDDEN for her. Manager / receiver / chef: FORBIDDEN.
- B (same billing account, not my membership), M (manager-only), X (another account) never appear in any payload; a forged session restaurant id → FORBIDDEN.
- Hebrew-first RTL, every pair AA, ₪ only via `formatIls()`, tiers T1–T4, partner wording (בקשות זיכוי פתוחות, never דרישות / חוב).
- "worst branch → its biggest item" ≤2 clicks, 0 reloads (e2e, slice b).
