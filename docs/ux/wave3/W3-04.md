## 5. Acceptance (slice a)
- Ctrl/⌘K (by `code`, works on a Hebrew layout), `/` and the 🔍 open the palette; Esc closes and returns focus.
- `normalizeHe("צ׳יפס")` = `normalizeHe("ציפס")`; `"שָׁלוֹם"` → `"שלומ"`; `"ק\"ג"` = `"ק״ג"`; wrong layout
  `"akuo"` (typed on EN) finds `"שלום"`.
- Receiver: screens only; chef: orders + recipes records only; no ₪ in any result row.
- G-chords (`G` then `H/I/A/S/O/R/C`) within 1,000 ms; `?` opens the cheat sheet except on approvals routes;
  nothing fires inside an input. Every shortcut is listed in `lib/hotkeys.ts`; the cheat sheet renders from it.
- Light tokens only, one primary action, AA contrast, RTL.
