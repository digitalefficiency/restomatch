## 5. Acceptance
- One "דוח החודש" with exactly 3 tabs in the order above; `?tab=` is the only switch; default tab = המספר וההוכחה; the month survives tab changes.
- The leak ₪ is shown **once per tab view** (T1 on the proof tab; the total rows on the by tab equal it; not repeated on the sent tab outside the frames).
- Status pill: open month "פתוח · נכון ל-{date}"; frozen month "סגור · {date} · לא ישתנה". A frozen month shows the snapshot's number.
- Next steps are T2 rows with ₪ and a verb link (approvals, credit-request letters, recovery, link pending); the supplier step links to that supplier's page.
- 12-month select (this month + 11 back, Israel time); an aligned delta vs the previous month, red only when the leak grew.
- `/dashboard/reports/digest?month=X` answers 308 to `/dashboard/reports/monthly?tab=sent&month=X`.
- Frank Ruhl only on `.report-display` (cover + print header); no element under it renders ₪ (unit test on the cover strings + e2e computed-style check).
- Hebrew RTL, he/en parity, every pair AA, ₪ only via `formatIls()`; partner wording passes the glossary.
