# WA-02 · The agent core, read-only: role tools on the Ask engine, ₪ redacted before the model

**One line:** a free-text WhatsApp message from a bound person becomes a short, grounded Hebrew answer built from that person's own role tools. ₪ is formatted by the server and stripped for roles that may not see it. A deep link is appended after grounding. Taps, commands and media never reach the model. Nothing is written: proposals belong to WA-07.

## 5. Acceptance
1. Taps, commands and media make 0 model calls (20 inputs).
2. Off-list text gets the fixed refusal and no tool or model call.
3. Each role's tool list equals design §C.2's read column (minus tools that do not exist yet: close status, order guide); a forged tool name is refused and counted as `tool_not_allowed`.
4. Receiver: the JSON passed to the model and to the renderer has no key matching `/ils|agorot|amount|total|price|cost|vat|leak|delta/i` and no `₪`. Chef: leak, approvals and recovery tools are not callable; `orders.get` keeps ₪.
5. The model never writes ₪ or links: such prose is flagged and replaced by the server facts text; links are absolute go-links appended after grounding; an injected `https://evil.example` never reaches the outbound text.
6. Ungrounded answers are replaced by "לפי הנתונים: …".
7. A supplier whose only lines are MISSING_ON_INVOICE: "אין דליפה פתוחה מול {ספק} החודש."
8. The 31st model turn of a person in a day: "הגעתם למכסת השאלות להיום. הכפתורים ממשיכים לעבוד." plus model-off handling; another person is unaffected until the restaurant budget is spent.
9. Tenancy: tools run under the binding's restaurant on the app role (`current_user = restomatch_app`); `runAgent` refuses a connection that bypasses RLS; another tenant's supplier → "לא מצאתי ספק בשם הזה".
10. Off switch: `aiAssistant` off → fixed off reply, 0 model calls.
